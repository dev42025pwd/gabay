## 5. Final review (dod-reviewer)

"S3 is acceptable." Every finding reproduced as fixed. Checked on a scratch copy, never the repo: the new error patterns replace none of the 38 English ARB messages and none of the 8 server messages; the ARB checks really fail on a duplicate key and a missing Tagalog key; the manifest background equals the seed's light surface (`#FFF8F6`). Screenshots: the dark error banner is `#FFDAD6` on `#93000A` (7.24:1), the light success banner `#0A3D1E` on `#C8EFD3` (9.85:1); both have an icon and a written label, so status is never colour alone; no overflow. The thick outline around banners is the test renderer drawing shadows as solid blocks (`debugDisableShadows` is on in tests), not a defect.

Two nits:
- **NEW-1:** the `package:` pattern and the new "Concurrent modification" pattern would hide plausible future messages ("The map package: Level 2 failed to publish."; "Concurrent modification: someone else saved this venue first…").
- **NEW-2:** one changelog test compared counts only.

Both fixed in `9625105`:
- **NEW-1:** `package:` matches only as a package URI (`package:name/`), `dart:` only inside a stack frame; Dart's nameless error phrases match only at the start of the text (after optional whitespace and `Exception: `/`Error: `/`Unhandled Exception: ` wrappers); "Concurrent modification" only with "during iteration", as Dart prints it. Nine realistic domain sentences are must-pass tests; before the fix four failed (`Actual: 'Something went wrong. Please try again.'`). The 20 real thrown-error strings are each checked in six forms (bare, indented, after a newline, three wrappers) and all stay caught.
- **NEW-2:** the changelog test compares the bullet text with that surface's own ARB values. On a scratch copy wired to read the admin key, it failed: `Expected: ['The Gabay shopper app now starts…'] Actual: ['The Gabay admin page now starts…']`.

## 6. Design choices (coder's, accepted by dod-reviewer)

Wording outside a widget takes `AppLocalizations` as an argument; changelog bullets are functions into ARB; `SurfaceInfo.displayName(l10n)`; the generated l10n files committed and excluded from analysis; `untranslated.json` in `app/` and gitignored (`gen-l10n` does not create `build/` folders); the screenshot test loads Roboto from the Flutter SDK, adding no font asset; the 401 handler skips no paths by default (L126; Firebase Auth signs in outside the API); the debug logger prints method, path and status only, never headers; the banner names its dismiss button through Semantics; the entry-point tests call the real `main()`.

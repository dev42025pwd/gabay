## 1. What was built

- `functions/`: Express inside one Cloud Function (`onRequest`, `asia-southeast1`, `maxInstances: 1`), built lazily on the first request. Middleware in the order of standard §3.1 and the Blueprint: trust proxy (hop count) → `x-powered-by` off → helmet → CORS allow-list → 5 MB JSON limit → `requestId` → `actorContext` slot → audit slot → `/api` no-store → rate-limiter slot → routes → 404 → error handler.
- Config (`zod`, fail fast, root `.env` by absolute path through `process.loadEnvFile`), the `GlobalSetting` resolver (§3.16), the DB layer (`pg` pool, parameter-only `query`, `withTransaction`, connection failures tagged for 503), `{ error }` errors (23505 → 409, DB unreachable → 503), UTC dates, pagination (one WHERE for count and page, allow-listed sort), actor context (AsyncLocalStorage), `GET /api/health`, a pino logger with Cloud Logging severities.
- `db/tools/`: `migrate` (zero-padded, idempotent, a `-- verify:` query per file, run in a transaction) and `setup-db` (dev and `--bootstrap`, `--stop-on-error`, `--skip-*`). `db/migrations/` is empty, with its README. `db/schema.sql` unchanged.
- Packages, exact (Blueprint pins): express 5.2.1, pg 8.23.1, decimal.js 10.6.0, helmet 8.3.0, cors 2.8.6, express-rate-limit 8.7.1, multer 2.4.0, firebase-functions 7.4.0, firebase-admin 14.5.0, zod 4.6.5, pino 10.4.0; dev eslint 10.12.0, @eslint/js 10.0.1, globals 17.13.0, prettier 3.9.9. `db/tools`: pg 8.23.1.

## 5. Design choices (coder's, judged by dod-reviewer)

`process.loadEnvFile` instead of dotenv; `db/tools` with its own package; `createApp` with injected dependencies; DATE as text (UTC); defaults only for Blueprint keys with a stated default; the resolver takes `tenantId` from the caller; only 23505 → 409; fixed body-parser messages; `pageSize` cap 200; `setup-db` exit code = failed steps; a migration's verify query inside its transaction; the db layer tags connection failures so a non-database `ENOTFOUND` stays a 500; CORS exposes `X-Request-Id`; with `requestId` after the body limit (Blueprint order), a 413 or malformed-JSON response carries no request id.
